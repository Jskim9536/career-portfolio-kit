# 누락 자료와 질문

## 자료 확인표

| 항목 | 없을 때 할 일 |
|---|---|
| 프로젝트 문제·목표 | “어떤 대상의 어떤 문제를 다루며, 이번 범위는 어디까지인가요?” |
| 본인 기여 | “팀/오픈소스와 구분해 직접 맡은 구현·실험·분석은 무엇인가요?” |
| 결과와 조건 | “실제 측정한 값·조건·로그가 있나요? 없으면 검증 계획 초안으로 구성할까요?” |
| 근거 이미지 | “입력·출력·시스템 구조·실패 장면 중 제공할 수 있는 그림은 무엇인가요?” |
| 이름·소속·링크 | 출판·발표에 사용할 정확한 표기와 실제 링크를 확인한다. |
| 규격 | 주최 측 지침이 우선. 미지정 시 A4 세로 초안임을 밝힌다. |

한 번에 모든 칸을 질문하지 않는다. 자료를 읽고 가장 중요한 1~3개를 묶어서 묻는다. 개인 연락처는 포스터 목적에 필요한 경우에만 받는다.

## 질문 대화 예시

자료에 구조와 기술명은 있지만 기여와 결과가 없을 때:

> 초안 구조는 잡을 수 있습니다. 문구를 정확하게 쓰려면 세 가지가 필요합니다.
> 1. 팀 프로젝트에서 직접 맡은 부분은 어디인가요?
> 2. 실제 확인한 결과와 조건이 있나요? 없다면 현재 실행·검증 상태를 알려주세요.
> 3. 포스터에 넣을 수 있는 화면·구조도·그래프가 있나요?

사용자가 “아직 실험 전”이라고 답하면 ‘결과’ 자리에 그래프를 만들어 넣지 않는다. ‘검증 계획’으로 바꾸고 조건·지표·필요한 자료를 작성한다. “일단 초안만”이라면 저자 미확인·결과 미측정 같은 표기를 남긴다.

## 문구 편집 예시

- 약한 문구: “최첨단 AI를 활용한 혁신적인 자율주행 시스템.”
- 근거 중심 문구: “녹화 주행 영상에서 장애물 인식 실패 조건 분석.”
- 실제 수치 없음: “거리 조건별 인식 결과 비교 예정. 실측 전.”
- 시뮬레이션만 있음: “고정 경로 시뮬레이션에서 추종 오차 비교. 실차 미검증.”

각 수치에는 단위·모수·조건·원자료를 연결한다. 본인 진술만 확인된 내용은 사실 확인 대기 목록에 남기고 필요하면 추가 자료를 요청한다.

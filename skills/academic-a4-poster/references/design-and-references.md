# 디자인 기준과 레퍼런스

참고일: 2026-11-20. 아래 자료의 일반 원칙을 참고해 독립적인 템플릿을 작성했다. 원본 이미지·유료 템플릿을 포함하지 않는다.

## 확인한 레퍼런스

- [Academic Posters — Design by Jane / Behance](https://www.behance.net/gallery/47837481/Academic-medical-scientific-Research-Conference-Posters): 브라우저에서 실제 포스터를 시각 확인했다. 번호가 있는 섹션, 구분되는 방법·결과·논의·결론, 도식과 표의 배치를 참고한다. 원본은 대형 포스터이므로 A4에 그대로 축소하지 않는다.
- [Science Posters — Hannah Roderick / Behance](https://www.behance.net/gallery/107802889/Science-Posters): 실제 이미지를 시각 확인했다. 큰 타이포그래피와 일관된 그리드가 주제를 먼저 보이게 한다. 과학 홍보 포스터로, 연구 포스터의 학술 내용 구성 근거로 사용하지 않는다.
- [How to Make a Science Research Poster: Design — Carnegie Mellon University Libraries](https://guides.library.cmu.edu/scienceposters/design): 짧은 문구, 그림 중심 설명, 일관된 폰트·정렬·여백 원칙을 참고한다. 대형 포스터용 글자 크기를 A4에 그대로 적용하지 않는다.

웹 도구에서는 Behance 접근이 403으로 막혔으나 브라우저로 확인했다. 이후 실행 환경에서 접근할 수 없으면 해당 제한을 밝히고 저장된 원칙이나 사용자가 준 레퍼런스로 작업한다.

## 내용에 따른 디자인 선택

| 방향 | 적합한 내용 | 배치 |
|---|---|---|
| Academic Clean (기본) | 방법·조건·비교 결과가 있는 공학 과제 | 제목·요약, 2열 본문, 큰 결과 그림, 하단 출처 |
| Evidence First | 명확한 결과와 그래프가 핵심 | 상단 결론·대표 근거, 아래 방법과 한계 |
| System Overview | 수치보다 구조·통합·구현이 핵심 | 중앙 구조도, 주변 문제·담당 모듈·검증 범위 |

이는 이 스킬의 편집 방향이며 Behance의 공식 분류가 아니다. 포스터 목적과 자료에 맞춰 선택하고 모든 방향의 구현을 강제하지 않는다.

## A4 조판 기본값

- 세로 210×297mm, 내부 여백 약 12mm, 2열 간격 약 7mm.
- 흰 바탕·짙은 본문·강조색 하나. 색만으로 결과를 구분하지 말고 라벨·선 종류도 사용한다.
- 제목 약 23~27pt, 섹션 12~14pt, 본문 10~11pt, 캡션·출처 약 9pt부터 시작한다. 실제 길이에 맞춰 조정하되 작은 글씨로 내용을 욱여넣지 않는다.
- Pretendard 우선, 미설치 시 한글 지원 시스템 폰트. 웹 폰트 다운로드를 필수로 하지 않는다.
- 그림·그래프·시스템 구조가 내용의 중심이어야 한다. 배경 장식·아이콘·배지가 실험 근거보다 크지 않게 한다.
- 한 페이지에서 읽을 핵심만 남기고 상세 코드·보고서는 실제 링크로 연결한다.

연구 데이터가 없을 때 장식 그래프를 생성하지 않는다. 안내용 빈 그림 영역은 명시적으로 ‘자료 필요’라고 표시하고 초안으로 전달한다.

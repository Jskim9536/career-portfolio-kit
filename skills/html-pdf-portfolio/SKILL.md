# HTML PDF Portfolio

실제 프로젝트 자료를 근거로 수정 가능한 HTML과 PDF 포트폴리오를 만든다. 특정 개인의 이력·회사·경로에 의존하지 않는다.

## 자료와 질문

먼저 코드·README·기존 포트폴리오·로그·이미지를 읽어 프로젝트 목록과 근거를 정리한다. 희망 직무, 제출 조건, 본인 역할, 결과, 누락 자료를 확인한다. 자료에서 답을 찾을 수 없는 중요한 질문만 최대 3개로 묶어 묻는다. 사용자 답이 필요한 주장·저자명·역할은 확정하지 않는다. 답을 기다리는 동안 근거 목록과 문서 구조를 만든다.

모든 프로젝트는 목록에 남기되, PDF는 대표 사례를 선별해 설명한다. 목표와 실측, 시뮬레이션과 실기, 팀 성과와 본인 기여를 구분한다. 수치가 없으면 미측정으로 표시하고 가장 작은 추가 측정을 제안한다. 근거가 없는 그림은 캡처 요청으로 남긴다.

## 작성 전: JD 기준과 인수조건

JD가 있으면 사례·슬라이드 작성 전에 [공유 JD 기준](../jd-application-review/references/jd-criteria.md)을 읽고 필수요건·주요업무·우대사항을 실제 프로젝트 근거와 연결한다. 기준·배점·인수조건을 개인 QA 폴더에 먼저 기록하고 각 기준을 입증할 사례와 시각 자료를 고른다. 같은 지원 건의 이력서 기준이 있으면 재사용한다. 사용자가 요청한 모든 언어 버전을 포함하고 자료가 없는 경험은 없는 상태로 남긴다. JD가 없으면 목표 직무 기반 임시 구성 계획을 사용하며 JD 점수를 만들지 않는다.

리뷰에서 기준 ID·수정 항목을 받았다면 기준을 바꾸지 않고 기존 v1을 보존해 v2를 작성한다. 관련 이력서와 모든 언어에 기간·역할·성과를 일치시킨다.

## 구성

마감과 분량을 우선 적용한다. 10페이지 이내 요청이면 기본 8페이지로 시작한다: ① 표지·목표 직무 ② 프로젝트·역량 요약 ③ 대표 사례의 문제 ④ 구조·본인 기여 ⑤ 기술 선택·구현 ⑥ 실험·결과 ⑦ 실패·한계·활용 ⑧ 보조 경험·다음 단계·링크. 사례 수에 따라 합치거나 나누되 빈 페이지를 늘리지 않는다.

페이지마다 핵심 주장, 시각 근거, 출처를 정한다. 제목은 실제 확인한 결론으로 쓰고, 결론을 낼 수 없으면 목표나 질문으로 쓴다. 내부 기술명은 처음에 설명한다. 기술 목록보다 선택 이유·직접 수행·검증을 우선한다.

## 구현과 출력

[layout-and-export.md](references/layout-and-export.md)를 읽는다. [portfolio.html](assets/portfolio.html)은 편집용 시작 템플릿이며 학생의 실제 실적이 아니다. 복사한 뒤 내용과 자산을 교체한다.

- 한 페이지를 1600×900 고정 좌표로 구성한다. 브라우저에서는 페이지 전체를 비율로 축소하며 내부 내용을 화면 폭에 따라 재배치하지 않는다.
- Pretendard를 우선 사용하되 설치되지 않았으면 한글 지원 폰트로 대체하고 출력 결과를 확인한다. 외부 폰트 다운로드를 필수로 만들지 않는다.
- 이미지는 `object-fit: contain`, 링크는 실제 `a href`로 넣는다. 외부 이미지 핫링크보다 출처가 기록된 로컬 자산을 사용한다.
- Chromium 인쇄로 같은 HTML을 PDF로 내보낸다. 텍스트·링크를 보존하고 스크린샷을 PDF로 합치지 않는다.

출력 후 페이지 수·16:9 비율·링크·한글 글리프를 확인한다. 모든 페이지를 렌더링해 겹침·잘림·여백을 점검한다. 내용이 넘치면 우선 문구와 중복을 줄이고 핵심 근거 크기를 유지한다.

## 전달

HTML·PDF·사용 자산·근거 및 미확정 목록을 제공한다. 코드·README·포트폴리오의 기간·역할·결과가 일치하는지 확인한다. 생성·실행·시각 검증 중 실제 수행한 범위를 정확히 보고한다. 원본 자료를 공개 저장소로 자동 업로드하지 않는다.

JD가 있는 새 작성의 1차 출력 후 [JD 리뷰·수정 스킬](../jd-application-review/SKILL.md)로 같은 기준을 채점하고 수정·재출력·재검수한다. 사용자 지정 범위가 우선한다. **리뷰 스킬의 수정 단계에서 호출됐으면 재귀적으로 리뷰를 호출하지 않고** 갱신한 모든 언어의 HTML·PDF와 검사 결과를 반환한다.

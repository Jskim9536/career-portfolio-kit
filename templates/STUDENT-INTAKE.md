# 학생 사전 질문지

- 이름 / 전공 / 학년:
- 희망 직무 1개 / 관심 분야:
- 관련 채용공고 링크 1개(없으면 생략):
- GitHub / 기존 PPT / 기술블로그 링크:
- 사용 가능한 노트북 환경 / 현재 실행 가능한 도구:

## 프로젝트마다 작성: 최대 2건

1. 프로젝트 이름·기간·팀 인원:
2. 해결하려고 한 문제와 사용 환경:
3. 입력과 출력:
4. 내가 직접 한 일과 담당 파일·모듈:
5. 팀원 또는 오픈소스가 담당한 일:
6. 지금 실행할 수 있는가? 마지막 실행 환경·시점:
7. 보여줄 수 있는 코드·영상·로그·그래프:
8. 비교한 방법·조건과 실제 측정값:
9. 가장 어려웠던 문제·실패와 수정 내용:
10. 아직 확인하지 못한 점 / AI 활용 범위:

수치나 근거가 없으면 “미측정” 또는 “자료 없음”으로 적는다. 목표값과 실제 측정값을 구분한다.

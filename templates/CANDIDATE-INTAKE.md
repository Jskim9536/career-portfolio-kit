# 지원자 사전 질문지

학생·신입·경력자·경력 전환자 모두 사용할 수 있다. 자료에 이미 답이 있으면 다시 작성할 필요가 없고, 업무상 비공개 정보는 승인된 개인 작업 공간에서만 다룬다.

- 이름 / 공식 영문 이름 / 지원 문서에 넣어도 되는 연락처:
- 목적: 첫 취업 / 이직 / 경력 전환 / 기타:
- 목표 회사·직무 / JD 원문 또는 링크:
- 경력 단계와 기간 / 재직·활동·학력 상태:
- 필요한 문서·언어 / 제출 형식·분량·마감:
- 경력 정본 / 기존 이력서·경력기술서·포트폴리오 위치:
- 공개 가능한 작업 결과·근거 링크 / 공개하면 안 되는 정보:

## 대표 경험별 입력

1. 회사·기관·프로젝트, 기간, 실제 직함과 역할:
2. 고객·사용자·업무 맥락과 해결할 문제:
3. 직접 책임진 범위와 팀·협력자 담당 범위:
4. 내린 판단, 비교한 대안, 실제 수행한 행동:
5. 완성한 결과물·변경한 프로세스·확인한 결과:
6. 수치가 있다면 정의·단위·기준·측정 기간·출처:
7. 보여줄 수 있는 문서·화면·분석·디자인·운영 기록·코드:
8. 어려웠던 문제·실패·수정·남은 한계:
9. 사용한 도구와 실제 활용 범위 / AI 도움과 본인 기여:
10. 고객명·내부 수치·이미지·제3자 정보의 공개 승인 범위:

없는 수치·결과는 만들지 않는다. 목표·진행 중·실제 달성을 구분한다. 코드나 실험이 없는 직무는 관련 없는 항목을 생략하고 실제 업무 산출물을 제시한다.

## 작성·리뷰 준비

- JD와 직접 연결되는 경험 / 인접 경험 / 없는 근거:
- 대표 사례와 보조 사례:
- 반드시 확인할 사실과 기밀·개인정보:
- 만들 문서와 공유할 JD 기준 ID:
- 추가 자료 없이 고칠 수 있는 내용 / 본인 확인이 필요한 내용:
